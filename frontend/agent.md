Create a clean, modern, professional SaaS dashboard UI for an AI-powered retail inventory management platform called **“SmartStock AI”**.

The dashboard should be **minimal, neat, highly readable, beginner-friendly, and visually organized**, with a light background, soft pastel cards, rounded corners, subtle shadows, blue/purple/green accent colors, clean typography, and professional business software styling.

### Header

Show:

* SmartStock AI logo and name
* Subtitle: “AI-Powered Pricing • Replenishment • Inventory Balancing”
* Right side: “AI SYSTEM ACTIVE” status indicator
* Notification and user profile icons

### Left Sidebar Navigation

Create a simple vertical sidebar with icons and labels:

* Overview
* AI Decision Center
* Demand Forecast
* Inventory Management
* Multi-Store Balancing
* Dynamic Pricing
* AI Recommendations
* Simulation
* Analytics & Insights
* Decision History

Highlight **Overview** as the active section.

### Top KPI Cards

Use four simple cards:

* Revenue
* Profit
* Inventory
* Risks

Do not overcrowd the cards. Use a large number, a small trend indicator, and a tiny line chart.

### Main Dashboard

#### 1. AI Decision Center

Make this the main visual section.

Show four AI agents communicating in a clear sequence:

* Pricing AI
* Inventory AI
* Rebalancing AI
* Decision AI

Display their messages as clean conversation cards, showing how the agents analyze different factors and finally produce one coordinated decision.

At the bottom show:
**Action Approved**

#### 2. Inventory Health

Show a simple visual overview of inventory condition using progress bars.

Include categories such as:

* In Stock
* Low Stock
* Out of Stock
* Overstock

Also show two clear alerts:

* Stockout Risks
* Overstock Risks

#### 3. Multi-Store Inventory

Show three simple store cards:

* Store A
* Store B
* Store C

Visually show stock movement between stores using an arrow:

**Store B → Store A**

with a small label showing the transferred quantity.

#### 4. AI Recommendation

Create a highlighted recommendation card containing:

* Recommended action
* Reason
* Expected impact

Add two buttons:
**“Why this decision?”**
**“Apply Action”**

#### 5. 90-Day Simulation

Create a clean comparison section:

**Current Strategy VS AI Strategy**

Compare:

* Stockouts
* Wastage
* Total Profit
* Inventory Utilization

Add a prominent button:

**▶ Run Simulation**

### Design Requirements

* Keep the dashboard uncluttered.
* Use generous spacing.
* Make every section visually distinct.
* Use icons consistently.
* Use short labels instead of long paragraphs.
* Make the AI agent conversation easy to understand at first glance.
* Use charts only where they provide useful information.
* Avoid excessive gradients or complicated 3D effects.
* Make it look like a real startup SaaS product, not a generic admin panel.
* Desktop dashboard, 16:9 composition.
* High-resolution UI mockup.
* Professional fintech/SaaS-quality interface.
* Clear visual hierarchy.
* No unnecessary products, brands, photographs, or decorative elements.

### Core Visual Story

The dashboard should communicate this flow immediately:

**DATA → AI AGENTS → COLLABORATION → DECISION → ACTION → RESULT**

The overall impression should be:

**“A team of AI agents working together to make smarter pricing, replenishment, and inventory-balancing decisions.”**
